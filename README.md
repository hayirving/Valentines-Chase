# Valentine's Chase

## Project info

**URL**: https://lovable.dev/projects/6df71081-129b-4212-863f-0a5b1f1dce47

This is a lovable vibe-coded webpage suitable for mobile and desktop for Valentine's Day!

Send a 'Will you be my valentine?' to the lucky person in your life, and watch as they struggle to press 'No'. They will only be able to press 'Yes!' and a celebratory gif will appear after.
